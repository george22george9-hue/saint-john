# اجتماع القديس يوحنا الحبيب للشباب ⛪

**موقع ويب متكامل (Full-Stack Web Application)** تم تصميمه وتطويره لخدمة "اجتماع القديس يوحنا الحبيب للشباب" في كنيسة الشهيد العظيم مارجرجس بسندبيس. 
يهدف الموقع إلى ربط الشباب بأنشطة الاجتماع، وتوفير منصة للتواصل، ومتابعة أحدث الفعاليات بطريقة عصرية، جذابة، واحترافية.

---

## ✨ مميزات المشروع (Features)

### 1. واجهة المستخدم (Frontend - Public Portal)
*   **تصميم عصري (UI/UX):** واجهة جذابة تدعم التأثيرات الحركية (AOS Animations) وتصميم الزجاج الشفاف (Glassmorphism).
*   **عداد تنازلي تفاعلي (Live Countdown):** عداد تلقائي يحسب الأيام والساعات المتبقية حتى ميعاد الاجتماع القادم (يوم الجمعة الساعة 7:00 مساءً).
*   **نظام التبويبات (Interactive Tabs):** واجهة مدمجة للتنقل بسهولة بين تفاصيل "برنامج اجتماع الجمعة" و"برنامج النشاط الصيفي (الأحد)".
*   **قسم الأخبار والفعاليات:** يتم سحب الأخبار والأنشطة ديناميكياً من قاعدة البيانات ليتم عرضها في بطاقات (Cards) تفاعلية.
*   **صندوق الأسئلة والاقتراحات (Q&A Form):** زر عائم (FAB) يفتح نافذة منبثقة (Modal) تتيح للشباب إرسال أسئلة روحية، اقتراحات للخدمة، وطلبات ترانيم في سرية تامة إلى الخدام.
*   **متجاوب بالكامل (100% Responsive):** متوافق مع كافة أحجام الشاشات (الهواتف، الأجهزة اللوحية، أجهزة الكمبيوتر).

### 2. لوحة تحكم الخدام (Admin Dashboard)
*   **نظام تسجيل الدخول (Authentication):** لوحة تحكم محمية بالكامل باستخدام (JWT - JSON Web Tokens) لضمان عدم دخول أي شخص غير مصرح له.
*   **إدارة الأخبار والأنشطة:** يمكن للأدمن إضافة أنشطة جديدة أو حذف الأنشطة القديمة، وتنعكس التغييرات فوراً على الصفحة الرئيسية.
*   **صندوق الوارد (Feedback Inbox):** صفحة مخصصة لقراءة الأسئلة والاقتراحات وطلبات الترانيم المرسلة من الشباب.
*   **إدارة إعدادات الموقع:** إمكانية تعديل المواعيد النصية (مثل ميعاد الجمعة وجدول يوم الأحد) مباشرة من لوحة التحكم.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

### الواجهة الأمامية (Frontend)
*   **HTML5 & CSS3:** لبناء هيكل الصفحات والتنسيقات.
*   **JavaScript (Vanilla JS):** لبرمجة التفاعلات (العداد، التبويبات، وإرسال البيانات).
*   **Bootstrap 5 (RTL):** لضمان استجابة التصميم وتناسقه مع اللغة العربية.
*   **مكتبة AOS:** لإضافة المؤثرات الحركية أثناء التمرير (Animate On Scroll).
*   **Google Fonts:** استخدام خط **Cairo** الاحترافي للغة العربية.
*   **FontAwesome:** لأيقونات الواجهة الرسومية.

### الواجهة الخلفية (Backend - REST API)
*   **Node.js & Express.js:** بناء سيرفر سريع ومستقر يقدم واجهات برمجة التطبيقات (RESTful API).
*   **SQLite (better-sqlite3):** قاعدة بيانات خفيفة وسريعة لحفظ (المستخدمين، الأنشطة، الأسئلة، والإعدادات).
*   **JSON Web Tokens (JWT):** لحماية مسارات الأدمن وتأمين تسجيل الدخول.
*   **Bcrypt.js:** لتشفير كلمات المرور في قاعدة البيانات.

---

## 🗄️ هيكل قاعدة البيانات (Database Schema)

المشروع يحتوي على 4 جداول أساسية في SQLite:
1.  **`users`**: تخزين بيانات الأدمن (البريد الإلكتروني، كلمة المرور المشفرة).
2.  **`announcements`**: تخزين أنشطة الكنيسة (العنوان، التاريخ، التفاصيل).
3.  **`inquiries`**: تخزين أسئلة الشباب (الاسم، الترنيمة المطلوبة، نص الرسالة).
4.  **`settings`**: تخزين نصوص الإعدادات الديناميكية (مواعيد الاجتماع).

## 🚀 كيفية تشغيل المشروع محلياً (Local Setup)

1.  تأكد من تثبيت **Node.js** على جهازك.
2.  قم بتحميل المشروع وافتح الـ Terminal في مسار المجلد.
3.  اكتب الأمر التالي لتثبيت المكتبات المطلوبة:
    ```bash
    npm install
    ```
4.  لتشغيل السيرفر وقاعدة البيانات، اكتب:
    ```bash
    npm start
    ```
